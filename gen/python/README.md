## Run

With [uv](https://docs.astral.sh/uv/); uvx installs the package and its runtime on first use:

```console
uvx codapact-jira --help
uvx --refresh-package codapact-jira codapact-jira --version   # update to the latest
```

Requires Python 3.13 or newer.

## Credentials

Save once in the OS keyring with `uvx codapact-jira auth login`, or set per shell:

- `basic`: `JIRA_BASIC_USERNAME`, `JIRA_BASIC_PASSWORD`. Use your Atlassian account email as the username and an API token as the password (create one at https://id.atlassian.com/manage-profile/security/api-tokens).
- `session`: `JIRA_SESSION`. For sites where API tokens are disabled: signs in through a browser window and sends the session cookies.

`<VAR>_COMMAND` runs a command that prints the secret (e.g. a password manager). `uvx codapact-jira doctor` checks settings, credentials, and connectivity.

## Use

```console
uvx codapact-jira issues get --issue-id-or-key PROJ-1 --query fields.description
uvx codapact-jira issue-search search-issues --jql 'project = PROJ ORDER BY created DESC' --fields summary,status
uvx codapact-jira issues create --fields '{"project":{"key":"PROJ"},"issuetype":{"name":"Task"},"summary":"Fix login"}' --markdown @description.md
uvx codapact-jira issue-comments add-comment --issue-id-or-key PROJ-1 --markdown 'Deployed :white_check_mark:'
uvx codapact-jira describe --brief   # every command, for scripts and agents
```

As a library:

```python
from codapact_jira import Client

client = Client()
```

## Markdown

Rich text is Markdown both ways. `--markdown TEXT|@file|@-` sets an issue description,
a comment or a worklog comment; a Markdown string for `description`, `environment`,
a comment `body` or a worklog `comment` inside JSON arguments is converted too, and every
ADF document in a response comes back as Markdown. `--doc-format adf` (or
`JIRA_DOC_FORMAT=adf`) keeps raw ADF. The dialect (panels as `> [!NOTE]`, `:status[DONE]{color=green}`,
mentions, Jira emoji such as `:tick:`) is documented by `uvx adflux syntax`.

## Sign-in

Set `--base-url` (or `JIRA_BASE_URL`) to your site, for example
`https://your-site.atlassian.net`. An API token is preferred: `codapact-jira auth login
--scheme basic` with your Atlassian email and a token from
https://id.atlassian.com/manage-profile/security/api-tokens. Where API tokens are
disabled, `codapact-jira auth login --scheme session` opens a browser window for
single sign-on, saves the session cookies in your keyring, and renews them without a
window until your identity provider asks for you again. Browser sign-in needs Chrome,
Edge or `playwright install chromium`.
